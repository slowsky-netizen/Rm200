# X-Rite CAPSURE RM200 Color Advisor

GUI-приложение на Python для спектрофотометра **X-Rite RM200**. Позволяет считывать измерения с прибора, сравнивать два цвета, строить рекомендации по коррекции CMYK, работать с пользовательскими палитрами и полностью управлять самим устройством через USB.

В основе лежит библиотека [`rm200lib`](https://github.com/raburton/rm200lib) от Richard Burton.

##Возможности

### Основное

* **Измерения и коррекция CMYK** — эталон vs. образец, усреднение нескольких измерений, рекомендация вида «на 10% больше Cyan, на 3% меньше Yellow».
* **Пользовательские палитры** — неограниченное число своих палитр, авто-имена, ручное переименование, импорт/экспорт JSON.
* **Режим подбора смеси** — для эталонного цвета подбирается смесь из N ближайших цветов палитры с процентами и оценкой ΔE.
* **Ручной ввод эталона** — по CMYK или RGB, если под рукой нет образца для измерения.
* **ICC-профиль принтера** — поддержка в режиме CMYK для более точных расчётов.

### Управление устройством

* **Информация** — Info, FW, BL, SN, ChipID, Battery, Mode, Time, Aperture, Temperature, DeltaE.
* **Файлы** — список, скачивание, загрузка, удаление, дамп `MeasDataV05.dat`.
* **Fan Decks** — список, активация, деактивация, удаление, загрузка `.fdk`.
* **Калибровка** — состояние, время до истечения, `BackupCalibData`, чтение `Versions.dat`.
* **Экран и клавиатура** — скриншот LCD, эмуляция кнопок прибора.
* **Live Preview** — потоковое превью с сенсора в окне программы.
* **Консоль** — `GenericCmd` с предустановленными командами, `UnlockExtendedCommands`.

## Требования

### Операционная система

* Windows 10/11 (x86_64)
* Linux (Ubuntu 20.04+, Debian 11+, Fedora 35+)
* macOS 10.15+

### Аппаратное обеспечение

* Спектрофотометр **X-Rite RM200** (любая ревизия)
* USB-кабель из комплекта (или качественный короткий USB 2.0)
* Свободный USB-порт, желательно **2.0** на задней панели ПК

### Программное обеспечение

* **Python 3.8+** ([скачать](https://www.python.org/downloads/))
* **pip** (идёт вместе с Python)
* **pyusb** — работа с USB-устройствами
* **pillow** — для Live Preview и ICC-профилей (опционально)

### Зависимости Python

```bash
pip install pyusb pillow
```

Если планируете использовать ICC-профили и Live Preview — Pillow обязателен.

Установка

Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/yourname/rm200-color-advisor.git
cd rm200-color-advisor
```

Шаг 2. Установка библиотеки rm200lib

Библиотека не публикуется на PyPI, поэтому её нужно скачать отдельно:

```bash
git clone https://github.com/raburton/rm200lib.git
```

Файл rm200lib.py из этого репозитория нужно положить в ту же папку, где находится cmyk_advisor_gui.py.

Итоговая структура папки после установки:

```
rm200-color-advisor/
├── cmyk_advisor_gui.py
├── rm200lib.py                ← из репозитория raburton
├── palettes.json              ← создастся автоматически
└── README.md
```

Шаг 3. Установка зависимостей

```bash
pip install pyusb pillow
```

На Linux дополнительно может понадобиться пакет libusb-1.0-0-dev:

```bash
sudo apt install libusb-1.0-0-dev          # Debian/Ubuntu
sudo dnf install libusb1-devel              # Fedora
sudo pacman -S libusb                       # Arch
```

На macOS через Homebrew:

```bash
brew install libusb
```

Шаг 4. Первый запуск

```bash
python cmyk_advisor_gui.py
```

Если всё установлено верно — откроется окно, и через несколько секунд в статус-баре появится сообщение о подключении к устройству (если оно подсоединено).

Подключение устройства

1. Физическое подключение

Подключите RM200 к компьютеру через USB-кабель из комплекта. Устройство должно включиться и отобразить основной экран.

Рекомендации:

· Подключайте RM200 напрямую к заднему USB-порту материнской платы. Не через USB-хаб, монитор, док-станцию или переднюю панель корпуса. Прибор во время измерения потребляет больше тока (вспышка лампы), и слабый порт приводит к разрыву USB-соединения.
· Используйте порт USB 2.0, а не USB 3.0/3.1. На некоторых контроллерах USB 3.x старые устройства работают нестабильно.
· Если кабель из комплекта повреждён или слишком длинный — замените на короткий (до 1 м) качественный USB-кабель.

2. Отключение энергосбережения USB (Windows)

Windows может отключать питание USB-порта для экономии энергии, что приводит к ошибкам «0030 Ошибка USB. Восстановление USB-подключения».

1. Откройте Диспетчер устройств (Win+X → Диспетчер устройств).
2. Разверните Корневые USB-концентраторы (USB Root Hub).
3. Для каждого концентратора:
   · Правый клик → Свойства.
   · Вкладка Управление электропитанием.
   · Снимите галочку «Разрешить отключение этого устройства для экономии энергии».
4. Повторите для всех корневых USB-концентраторов в списке.

3. Установка libusb-драйвера (Windows)

Стандартный HID-драйвер Windows не даёт прямого доступа к vendor-specific устройству через pyusb. Нужно заменить драйвер на WinUSB или libusb-win32.

Через Zadig:

1. Скачайте Zadig (не требует установки).
2. Запустите zadig.exe от имени администратора.
3. В меню Options → List All Devices.
4. В выпадающем списке найдите RM200 или устройство с Vendor ID 0x0765.
5. Убедитесь, что в правом поле выбран драйвер WinUSB (или libusb-win32).
6. Нажмите Install Driver (или Replace Driver).
7. Дождитесь завершения, закройте Zadig.

Проверка: откройте Диспетчер устройств — RM200 должен появиться в разделе «USB-устройства» или «Устройства USB» с типом драйвера WinUSB device.

4. Проверка подключения (все ОС)

Запустите программу:

```bash
python cmyk_advisor_gui.py
```

В статус-баре внизу окна появится информация:

```
Подключено.  FW: 2.16  SN: 0010079826  Записей: 12  Время RM200: 2026-09-24 14:39:38  Последняя в файле: 2026-09-24 14:39:38 (2 мин назад)
```

Если вместо этого вы видите «Нет подключения» — см. раздел Частые проблемы.

5. Разрешения на Linux (udev)

На Linux обычный пользователь по умолчанию не имеет доступа к USB-устройствам. Создайте правило udev:

```bash
sudo nano /etc/udev/rules.d/99-rm200.rules
```

Вставьте:

```
SUBSYSTEM=="usb", ATTR{idVendor}=="0765", MODE="0666", GROUP="plugdev"
```

Сохраните (Ctrl+O, Enter, Ctrl+X), затем:

```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
```

Убедитесь, что ваш пользователь в группе plugdev:

```bash
sudo usermod -aG plugdev $USER
```

Перелогиньтесь и переподключите RM200.

6. Разрешения на macOS

На macOS обычно достаточно установить libusb через Homebrew. Если устройство не видно — проверьте System Settings → Privacy & Security → нет ли запроса на разрешение USB-устройства. Обычно macOS сам запрашивает при первом обращении.

7. Проверка на уровне USB (диагностика)

Linux/macOS:

```bash
lsusb | grep 0765
```

Должно показать:

```
Bus 001 Device 005: ID 0765:6001 X-Rite, Inc.
```

Windows — в Диспетчере устройств RM200 должен присутствовать в списке USB-устройств без жёлтого значка ошибки.

Если lsusb не показывает RM200 — проблема на уровне железа/кабеля. Если показывает, но программа не подключается — проблема с драйвером или правами.

Быстрый старт

Сравнение двух цветов

1. Запустите python cmyk_advisor_gui.py.
2. Дождитесь автоматического подключения к RM200.
3. Измерение эталона:
   · Нажмите кнопку «Измерить» под левой панелью.
   · На RM200 нажмите кнопку измерения (или наведите прибор и нажмите).
   · В открывшемся диалоге выберите нужную запись двойным кликом (или выделите и нажмите «Добавить»).
4. Измерение образца:
   · То же самое для правой панели.
5. При необходимости добавьте ещё измерения — программа усреднит их.
6. Нажмите «Рассчитать» — в нижнем поле появится рекомендация по CMYK:

```
Эталон:   L*=  84.580  a*=  -5.190  b*=  72.060
Образец:  L*=  84.257  a*=  -7.946  b*=  79.727
ΔL*=+0.323  Δa*=+2.756  Δb*=-7.667  ΔE76=8.154

Расчёт по эвристике (ICC не указан).
Эталон CMYK:  C= 69.26 M= 46.35 Y=  3.96 K= 15.42
Образец CMYK: C= 71.55 M= 44.43 Y=  6.24 K= 15.74
ΔCMYK:       ΔC= -2.29 ΔM= +1.92 ΔY= -2.28 ΔK= -0.32

Коррекция: на 2% меньше Cyan, на 2% больше Magenta, на 2% меньше Yellow, Black не меняем.
```

Важно: сброс данных на флешку

RM200 сбрасывает файл MeasDataV05.dat на флешку не с каждым измерением, а батчами или при выключении. Поэтому после измерения свежая запись может ещё не появиться в файле.

Если ваш свежий замер отсутствует в диалоге выбора:

1. Закройте диалог кнопкой «Отмена».
2. Выключите RM200 кнопкой питания, подождите 3 секунды, включите снова.
3. Дождитесь авто-подключения.
4. Нажмите «Импорт после power-cycle» на главном экране — импортируются две последние записи (эталон = предпоследняя, образец = последняя).

Альтернатива — запустить с флагом --reconnect-after-measure:

```bash
python cmyk_advisor_gui.py --reconnect-after-measure
```

Программа после каждого измерения будет переподключаться к RM200 и пробовать получить свежие данные.

Если и это не помогает — используйте --reboot-after-measure:

```bash
python cmyk_advisor_gui.py --reboot-after-measure
```

Программа вызовет rm.Reboot() и дождётся переподключения. Работает, если в вашей прошивке RM200 поддерживается программный рестарт.

Работа с приложением

Приложение организовано в вкладки. Каждая вкладка — отдельная группа функций.

Вкладка «Измерения»

Основная вкладка для сравнения цветов. Содержит:

· Левая панель (ЭТАЛОН) — измерения эталонного цвета, кнопки Измерить, Импорт, Очистить.
· Правая панель (ОБРАЗЕЦ) — измерения подобранного цвета.
· Режим сравнения — выбор палитры (по умолчанию CMYK), N смешиваемых цветов, источник эталона.
· Результат — текстовое поле с расчётом.

Вкладка «Палитры»

Управление пользовательскими палитрами. Подробно — в разделе Палитры и подбор смеси.

Вкладка «Устройство»

Информация о приборе и базовые настройки:

· Информация — кнопка «Прочитать всё» выводит в лог значения всех доступных функций: GetInfo, GetSerialNum, GetFWInfo, GetBLInfo, GetChipId, GetBatteryState, GetDeviceMode, GetTime, GetTimeString, GetAperture, GetCalibrationState, GetTimeToCalibExpired, GetDeltaEParameter, MeasureTemperature.
· Режим устройства — получить/установить текущий режим (General, Sync, Remote, BatteryOnly).
· Время устройства — чтение и установка времени. Кнопка «Сейчас → Set» выставляет текущее системное время.
· Апертура — 0 (small), 1 (medium), 2 (large/auto).
· Сервис — кнопка ChipID для чтения уникального идентификатора.

Вкладка «Файлы»

· Обновить список — получить FileDir от RM200.
· Скачать выбранный — FetchFile выбранного файла.
· Загрузить на устройство — PutFile локального файла на RM200.
· Удалить выбранный — FileDelete.
· Сохранить MeasDataV05.dat — сохранить полный дамп измерений.

Вкладка «Fan Decks»

· Обновить список — GetFandecks.
· Активировать/Деактивировать — SetFandeckActive.
· Удалить — DeleteFandeck.
· Добавить Fan Deck (.fdk) — загрузка файла через PutFile.

Вкладка «Калибровка»

· Состояние — GetCalibrationState.
· Время до истечения — GetTimeToCalibExpired.
· BackupCalibData — с выбором режима 0/1/2.
· ReadVersionsDotDat — чтение системного файла.

Вкладка «Экран и клавиатура»

· Сохранить скриншот — SaveScreenshot в PNG/BMP.
· GetLcdData — сырые данные LCD в лог.
· Показать скриншот в окне — предпросмотр.
· Эмуляция клавиш — кнопки «Центр (Measure)», «Вверх», «Вниз», «Влево», «Вправо», «Preview (release)», «Preview (hold)», «Захват (Capture)».
· Прочитать состояние клавиш — GetKeyCode.

Вкладка «Preview»

Live Preview с сенсора RM200. Кнопки Запустить/Остановить Live Preview, Сделать скриншот Preview, поле интервала обновления (мс).

Вкладка «Консоль»

· UnlockExtendedCommands — с полем пароля (по умолчанию 873gwe31xah1).
· GenericCmd — с предустановленными командами (SetSerialNum, BackupCalibData, GetMultiColorCmd) и полями параметров v1–v6 и string.

Палитры и подбор смеси

Создание палитры

1. Откройте вкладку «Палитры».
2. Нажмите «Добавить палитру», введите имя (например, Мои пигменты).
3. Палитра появится в выпадающем списке сверху.

Добавление цветов

· Измерить новый цвет — то же, что обычное измерение, но результат сохраняется в палитру. Откроется диалог выбора записи из MeasDataV05.dat.
· Ручной ввод — открывает диалог с выбором CMYK или RGB. Введённое значение конвертируется в Lab.
· Переименовать цвет — выбрать строку и нажать кнопку. По умолчанию цвета называются Color 1, Color 2, ...
· Дублировать цвет — удобно, если нужно сделать вариацию.
· Удалить цвет — поддержка множественного выделения через Ctrl+клик.

Сохранение

Все изменения автоматически сохраняются в palettes.json рядом со скриптом.

Дополнительно:

· Меню Файл → Экспорт палитр (JSON) — сохранить все палитры в один файл.
· Меню Файл → Импорт палитр (JSON) — загрузить палитры из файла.

Подбор смеси

В рабочем процессе используется так:

1. Измерьте образец на вкладке «Измерения».
2. В блоке «Режим сравнения»:
   · Палитра — выберите вашу палитру.
   · N смешиваемых цветов — задайте максимальное число компонентов (например, 3).
   · Эталон — оставьте «Из измерений» или введите вручную.
3. Нажмите «Рассчитать».

Результат:

```
=== Режим: Палитра 'Мои пигменты' ===
Эталон (измерения)
Образец (среднее по 1 изм.)

Палитра:  Мои пигменты
Эталон:   L*=  52.100  a*=  18.300  b*=  22.400
Образец:  L*=  52.000  a*=  17.900  b*=  22.100  ΔE(эт-обр)=0.500

Предлагаемая смесь (для достижения эталона):
   42.13%  Color 17  (L= 52.100 a= 18.300 b= 22.400)
   28.42%  Color 5   (L= 48.700 a= 15.100 b= 19.200)
   29.45%  Color 42  (L= 55.600 a= 20.100 b= 24.800)

Итоговый цвет смеси: L*=52.134 a*=18.153 b*=22.271
ΔE смесь ↔ эталон: 0.823
```

Как это работает: для эталонного Lab находятся N ближайших цветов палитры по евклидову расстоянию. Веса распределяются обратно пропорционально квадрату расстояния. Доли меньше 0.1% отбрасываются, оставшиеся нормируются до 100%.

Ограничение: реальные пигменты смешиваются нелинейно. Программа считает смесь как взвешенное среднее в Lab. Это первое приближение, а не точная рецептура.

Ручной ввод эталона

Если у вас нет образца для измерения, но есть его точное значение:

1. В блоке «Эталон» выберите радиокнопку «Ручной CMYK» или «Ручной RGB».
2. Появятся поля ввода:
   · Ручной CMYK — C, M, Y, K в процентах.
   · Ручной RGB — R, G, B (0–255).
3. Заполните и нажмите «Рассчитать».

Как считаются переходы

· RGB → Lab — стандартное преобразование sRGB → линейный RGB → XYZ (D65) → Lab.
· CMYK → Lab — наивное преобразование: R = 255 · (1−C) · (1−K), аналогично для G и B, затем RGB → Lab. Это грубая оценка без ICC-профиля принтера. Для точных расчётов передайте ICC-профиль через --icc.

Live Preview

Вкладка «Preview» позволяет видеть изображение с сенсора RM200 в реальном времени.

Запуск

1. Нажмите «▶ Запустить Live Preview».
2. Программа вызовет StartPreview на RM200.
3. Затем в цикле будет запрашивать GetPreview и отрисовывать картинку.

Настройки

· Интервал (мс) — частота обновления. По умолчанию 500 мс. Увеличьте до 1000–1500 мс, если USB перегружен.

Сохранение кадра

· Сделать скриншот Preview — вызывает SavePreview и сохраняет кадр в BMP.

Остановка

· Остановить — прекращает цикл и вызывает StopPreview на RM200.
· При закрытии программы preview останавливается автоматически.

Расширенные команды

UnlockExtendedCommands

Некоторые команды RM200 защищены паролем. Пароль по умолчанию (из исходного кода rm200lib) — 873gwe31xah1.

1. Откройте вкладку «Консоль».
2. Поле Пароль уже заполнено значением по умолчанию.
3. Нажмите Unlock.

После успешной разблокировки становятся доступны команды, которые ранее возвращали ошибку.

GenericCmd

Вкладка «Консоль» → блок GenericCmd.

Предустановленные команды:

Имя Код Описание
SetSerialNum 0x032a Установка серийного номера
BackupCalibData (text) 0x0167 Резервное копирование калибровки (текстовый режим)
BackupCalibData (binary) 0x0167 Резервное копирование калибровки (binary-режим)
GetMultiColorCmd 0x7823 Пример кастомной команды

При выборе команды из списка поля v1–v6 и string автоматически заполняются.

Ручной ввод:

· Команда — код в hex (0x032a) или decimal.
· v1–v6 — параметры команды, каждый тоже можно указать в hex или decimal.
· String — строковый параметр, если команда его требует.

Нажмите «Отправить GenericCmd» — результат появится в логе.

---

Аргументы командной строки

```bash
python cmyk_advisor_gui.py [опции]
```

Опция Тип По умолчанию Описание
--icc PATH строка — Путь к ICC-профилю принтера. Используется в режиме CMYK для точных преобразований.
--aperture {0,1,2} целое 2 Апертура по умолчанию: 0 — small, 1 — medium, 2 — large/auto.
--timeout SEC float 180.0 Таймаут ожидания измерения после нажатия кнопки на RM200 (секунды).
--threshold PCT float 1.0 Порог «не меняем», в процентах. Изменения меньше порога игнорируются в рекомендации.
--reconnect-after-measure флаг выкл Переподключаться к RM200 после каждого измерения.
--reboot-after-measure флаг выкл Программно перезагружать RM200 после каждого измерения (если поддерживается прошивкой).

Флаги --reconnect-after-measure и --reboot-after-measure взаимоисключающие — можно указать только один.

Примеры

```bash
# Обычный запуск
python cmyk_advisor_gui.py

# С ICC-профилем принтера
python cmyk_advisor_gui.py --icc "C:\Profiles\Epson_3880.icc"

# Малый размер апертуры, порог 0.5%, авто-переподключение
python cmyk_advisor_gui.py --aperture 0 --threshold 0.5 --reconnect-after-measure

# Увеличенный таймаут, рестарт после каждого измерения
python cmyk_advisor_gui.py --timeout 300 --reboot-after-measure
```

Формат palettes.json

Файл создаётся автоматически при первом сохранении палитры. Формат:

```json
{
  "palettes": [
    {
      "name": "Мои пигменты",
      "entries": [
        { "name": "Color 1", "lab": [52.1, 18.3, 22.4] },
        { "name": "Color 2", "lab": [48.7, 15.1, 19.2] },
        { "name": "Красный тёплый", "lab": [55.6, 20.1, 24.8] }
      ]
    },
    {
      "name": "Краски принтера",
      "entries": [
        { "name": "Cyan",  "lab": [55.0, -37.0, -50.0] },
        { "name": "Magenta", "lab": [48.0, 75.0, -10.0] },
        { "name": "Yellow",  "lab": [89.0, -5.0, 93.0] },
        { "name": "Black",   "lab": [15.0, 0.0, 0.0] }
      ]
    }
  ]
}
```

Поля:

· name — имя палитры.
· entries — массив цветов.
· entries[].name — имя цвета.
· entries[].lab — массив [L, a, b] в CIE Lab.

Файл можно редактировать вручную, если нужно массово менять цвета.

Частые проблемы

«Нет подключения» в статус-баре

Причина: программа не может найти RM200 через USB.

Решения (по порядку):

1. Убедитесь, что RM200 включён и кабель подсоединён плотно.
2. Проверьте, что установлен libusb/WinUSB-драйвер (см. Подключение устройства, п. 3).
3. Попробуйте другой USB-порт, желательно USB 2.0 на задней панели ПК.
4. Закройте все приложения, которые могут держать RM200 (официальные утилиты X-Rite).
5. На Linux — проверьте права доступа через lsusb и правила udev.
6. Нажмите «Переподключить RM200» в программе.

Ошибка «0030 Ошибка USB. Восстановление USB-подключения»

Причина: RM200 кратковременно теряет USB-соединение после срабатывания лампы (пиковый ток превышает возможности порта).

Решения:

1. Подключите прибор напрямую к заднему USB-порту, не через хаб.
2. Отключите энергосбережение USB в Диспетчере устройств Windows (см. Подключение устройства, п. 2).
3. Запустите с --reconnect-after-measure.
4. Увеличьте POST_MEAS_PAUSE в начале скрипта до 3–4 секунд.
5. Используйте внешний USB-хаб с питанием (active hub), если задние порты не помогают.

Свежее измерение не появляется в диалоге выбора

Причина: RM200 сбрасывает MeasDataV05.dat на флешку батчами или при выключении, а не с каждым измерением.

Решения:

1. Закройте диалог кнопкой «Отмена».
2. Выключите RM200 кнопкой, подождите 3 сек, включите снова.
3. Нажмите «Импорт после power-cycle».
4. Или используйте --reconnect-after-measure / --reboot-after-measure.

Файлы .fdk скачиваются размером 0 байт

Причина: файлы фэндеков защищены прошивкой X-Rite. Прямое скачивание через стандартный USB-протокол обычно невозможно.

Решения:

1. Попробуйте UnlockExtendedCommands с паролем 873gwe31xah1 на вкладке «Консоль», затем повторите скачивание.
2. Используйте метод перехвата трафика CAPSURE Sync (см. блоги Richard Burton и Ivor Hewitt) — это позволяет получить те же файлы из облака X-Rite.
3. Прямой дамп NAND требует разборки устройства и JTAG — не рекомендуется.

Live Preview не работает

Решения:

1. Проверьте, что установлен Pillow: pip install pillow.
2. Некоторые прошивки RM200 не поддерживают потоковый GetPreview — функция может отсутствовать.
3. Увеличьте интервал до 1000–1500 мс, если USB перегружен.
4. Убедитесь, что StartPreview возвращает OK — смотрите лог внизу вкладки.

Программа зависает при измерении

Причина: USB-сбой или таймаут.

Решения:

1. Прервите (Ctrl+C в консоли или закройте окно).
2. Увеличьте --timeout (по умолчанию 180 секунд).
3. Проверьте кабель и порт.

Ошибки при загрузке rm200lib

Причина: rm200lib.py не найден рядом со скриптом, или установлен неверный pyusb.

Решения:

1. Убедитесь, что файл rm200lib.py лежит в той же папке, что и cmyk_advisor_gui.py.
2. Проверьте pip show pyusb — пакет должен быть установлен.
3. На Windows — убедитесь, что установлен libusb/WinUSB драйвер для RM200.

ICC-профиль не применяется

Решения:

1. Убедитесь, что путь к ICC-файлу корректен и файл существует.
2. Убедитесь, что установлен Pillow: pip install pillow.
3. ICC применяется только в режиме CMYK (палитра CMYK (встроенная)). В режиме пользовательской палитры ICC игнорируется.
4. Проверьте лог — при ошибке ICC программа переходит на эвристику и выводит сообщение.

Кнопки эмуляции клавиш не работают

Решения:

1. Убедитесь, что RM200 находится в правильном режиме (не в Sync, если применимо).
2. Проверьте лог внизу вкладки «Экран и клавиатура» — там будет сообщение об ошибке.
3. Некоторые прошивки RM200 могут не поддерживать эмуляцию клавиш.

Ошибка «Extended commands не разблокированы»

Решения:

1. Откройте вкладку «Консоль».
2. Проверьте, что пароль 873gwe31xah1 введён корректно.
3. Нажмите Unlock — смотрите лог.
4. Пароль может отличаться в вашей версии прошивки — проверьте исходный код rm200lib.py.

Ограничения

1. Смешивание цветов линеаризовано. Программа считает смесь как взвешенное среднее в Lab. Реальные пигменты смешиваются нелинейно (subtractive mix), поэтому результат — это первое приближение, а не точная рецептура.
2. CMYK → Lab без ICC наивно. Без профиля принтера преобразование CMYK в Lab выполняется через sRGB и даёт грубую оценку. Для точных расчётов используйте --icc printer.icc.
3. ICC-профиль принтера не работает в режиме «Палитра». Смесь строится напрямую по Lab.
4. Live Preview может быть недоступен на некоторых прошивках RM200.
5. Скачивание .fdk через USB ограничено производителем.
6. Программный рестарт (--reboot-after-measure) работает только если прошивка RM200 поддерживает команду Reboot() в основном режиме.
7. Эмуляция клавиш может не работать на старых прошивках.
8. Ограничение N смешиваемых цветов не гарантирует качество смеси. Если палитра плохо покрывает нужный оттенок, микс всё равно будет далёк — смотрите на ΔE смесь ↔ эталон.

Сборка в exe

Для распространения приложения без установки Python можно собрать standalone-exe через PyInstaller.

Установка PyInstaller

```bash
pip install pyinstaller
```

Сборка

```bash
pyinstaller --noconsole --onefile ^
            --name "RM200ColorAdvisor" ^
            --add-data "rm200lib.py;." ^
            --hidden-import usb.backend.libusb1 ^
            cmyk_advisor_gui.py
```

На Linux/macOS замените ^ на \ и ; на ::

```bash
pyinstaller --noconsole --onefile \
            --name "RM200ColorAdvisor" \
            --add-data "rm200lib.py:." \
            --hidden-import usb.backend.libusb1 \
            cmyk_advisor_gui.py
```

Готовый exe появится в папке dist/.

Важно для Windows

Для работы exe на машине без Python нужен libusb-1.0.dll. Можно:

1. Скачать с libusb.info.
2. Положить DLL рядом с exe.
3. Или использовать Zadig для установки драйвера — он сам подтянет нужную DLL.
